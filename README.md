- 決めた仕様（理由も一言）：
  - 数値は 本決まり（2026-11-19。index.html の UBC）：こうげき力6／HP ククドラ120・トキクイ240（やく20問＋30問。授業1回で おわる長さ。トキクイは 答えから式の ダメージが 大きいので 180→240）／トキクイは 5びょう→HP半分で3びょう／答えから式の 時間は 答えの数×1問の時間、ダメージは 6×答えの数／問題の わりあい ふつう4・虫食い4・答えから式2
