## 1. 目的とコンセプト
- **「九九モンスターを集めて育てよう」**（コレクション＋育成）＋**「ベストのじぶんに勝とう」**（ゴースト対戦）
- 図鑑の段階＝その式の到達度：たまご＝順番に唱えて言える／こども＝逆からでも言える／しんか＝段の中でばらばらでも言える／**かがやき＝ほかの段とまざっても、日をあけても言える**／**でんせつ＝3秒以内に すぐ言える**
- 毎日少しずつ取り組む習慣につなげる
- 競う相手は過去の自分だけにする

## 2. 九九モンスター
- 段ごとのすみか：1もり／2くさはら／3うみ／4そら／5かざん／6ゆきやま／7よぞら／8さばく／9たからの どうくつ
- 81ひき × 段階（たまご・こども・しんか・かがやき・でんせつ）＋ボス9ひき（「○○の ぬし」）
- かがやきは、しんかの姿に金の光（オーラと ✦）をつけて描く。でんせつは、3つ目のすがた（すみかの力をまとう。`KM.creatureSVG(a, b, 3)`）で描く
- 絵はすべてSVGで描く。オフラインで表示でき、ファイル1つにおさまる

## 3. ルール
| 段階 | どこで | 条件 |
|---|---|---|
| 🥚 たまご | 上り | 同じ式に**3回つづけて正解**（プレイをまたいで数える） |
| 🐣 こども（うまれる） | 下り | たまごになった**次の日以降**に正解 |
| ✨ しんか | 段のランダム・ランダム10問 | うまれた**次の日以降**に正解 |
| 🌟 かがやき | ランダム10問 | しんかした**次の日以降**に正解。※1の段と「○×1」はランダム10問に出ないので、段のランダムで かがやく |
| 🌈 でんせつ | ⚡3びょう チャレンジ | かがやいた**次の日以降**に正解。※1の段と「○×1」は、3びょう チャレンジがひらいた後、段のランダムで3秒以内に正解 |

| できごと | 条件 |
|---|---|
| にげる | なかまにした式を、下り・ランダム・ランダム10問でまちがえる（👣。段階は消えない）。**上りでは にげない** |
| とりもどす | にげた式に**2回つづけて正解** |
| ボス | 1つの段の9ひきがそろうと出現（一度出たら消えない） |

- 同じ日に何回正解しても、すすむのは1日1段階まで
- 図鑑の詳しい表示で「あした いこうに 下りで 7×8 に正解すると うまれるよ」のように、次に使う といかたと目標を出す

### といかたの解放（段ごと）

| ⬆️ 上り | はじめから | たまご |

## 8. 九九 ぜんぶ チャレンジ（ラスボス「ワスレドン」戦）v3.9（v3.17で「81問チャレンジ」から改名）
### 8-1. コンセプト
- ラスボスは**ワスレドン**（九九を わすれさせる やみ）。九九の習熟の最大の敵＝「わすれること」をそのまま敵にした
- ワスレドンが9つのすみかの光を うばっている。**ある段の9問に すべて正解すると、そのすみかを とりもどす**（景色に色がもどり、その段のぬしが なかまに加わる）。9つ とりもどす＝81問 やりきる＝たおす（81＝9×9 を物語の形にした）
- HPバーは すみかの色で9つに区切り、すみかを とりもどすたびに その色の区切りが くだける

### 8-2. ひらく条件
- **81ぴき ぜんぶ こども以上（`lv`≧1）**。にげている なかまも数える（段階は消えないため）。理由：なかまが「今のすがた」で攻撃する演出が、81問すべてで起きるようにする
- 一度ひらいたら閉じない（3びょう チャレンジと同じ）
- ロック中も メニューに ワスレドンの かげを出し、「🐣 81ぴき ぜんぶ うまれると、ワスレドンに いどめるよ　いま ○/81」と表示（毎日の練習の目標にする）

### 8-3. 出題
- 1の段をふくむ **81の式を1回ずつ、ランダムな順**に出す。4択
- **1問ごとに5秒**（リベンジの出題も同じ）。時間は答えが出た瞬間〜タップまで（攻撃・けがの演出は ふくめない）。のこり2秒でバーが赤く点滅。理由：ひらく条件が「こども以上」なので、3びょう（でんせつの基準）より少し やさしくしつつ、指で数えると間に合わない長さにする
- 演出のあいだは タイマーを止める（タイムにふくめない）

### 8-4. 正解したとき
- 答えた式のモンスターが、**今のすがたで ワスレドンを攻撃**する
  - 🐣こども・✨しんか：すみかの技（もり＝はっぱ、うみ＝みずでっぽう など）／🌟かがやき：金の光の大技／🌈でんせつ：すみかの力の必殺技（画面がゆれる）
  - 👣にげている なかま：「もどってきた!」と助けに来る
- **勝ち負けは81問をやりきったかだけで決まる**。段階で変わるのは演出の はでさだけ（育成が進んでいない子も勝てるように。かがやかせると技が かっこよくなる＝育てる理由）
- 攻撃の演出は1問 約0.6秒。タッチで とばせる
- れんぞく正解 5・10・20問で、なかま2〜3びきの合体攻撃

### 8-5. まちがえたとき（けが）
- その式のモンスターが反撃をうけて **けが**（ほうたいを まいて「けがの席」へ）。正しい答えを光らせて見せる。責めない言い方にする
- **ハート（チームのこころ）は3つ**。まちがえると1つ へる。**すみかを1つ とりもどすと1つ もどる**（最大3。v3.13〜）。連続正解では もどらない（がんばりの区切りでだけ回復させ、きんちょう感を保つ）
- **3問つづけて正解**すると、けがの なかまが1ぴき なおる（「○○が げんきに なった!」）。ハートは もどらない
- **けがをした式は 5〜8問あとに もう一度出す**（81問とは別に数える）。正解すると「リベンジ!」の特別攻撃で、そのモンスターが なおる。まちがえると ハートが へり、また あとで出す
- **時間切れも まちがいと同じ「けが」**：「⏰ ワスレドンの のろい!」を出し、正しい答えを光らせる。ハートが1つ へり、その式は あとでリベンジ出題（思い出せないうちに時間が切れる＝ワスレドンに わすれさせられた、と物語に合わせる）。3びょう チャレンジの時間切れ（記録しない・終了）とは あつかいがちがう
- ハートが0になったら「いったん すみかに もどろう」で終了。**とりもどした すみかの数**を出して記録する（前の自分と比べる）

### 8-6. 図鑑への記録
- **正解は記録する**（ランダム10問と同じあつかいで しんか・かがやきが進む）
- **まちがえても にげない**（戦いの中の けがだけ）。長い戦いで なかまが次々に にげるのは つらいため。累計誤答数（`m`）は ふやす

### 8-7. 最後とエンディング
- 最後の1問：とりもどした9ひきの ぬしがならび、その力で ワスレドンを **ふういん**（v3.16。HP1→0）
- エンディング：81ぴきが今のすがたでパレード →「スタッフ：きみと 81ぴきの なかま」
- クリア日を記録し、図鑑のボスわくの10番めに「ワスレドン」のシール（レジェンド）

### 8-8. データ（localStorage）
