# 【九九チャレンジ】引き継ぎメモ（2026-11-17）
- 対象・単元：2年 かけ算九九（最終レベル「81問チャレンジ」＝ラスボス「ワスレドン」戦）
- できていること：v3.10。はじめて いどむときに オープニング（9つのすみかの光がうばわれ、なかま81ぴきが立ち上がる6場面・スキップ可・メニューから見なおせる）。81の式を1回ずつランダムに出題（1問5秒）。正解でその式のなかまが今のすがたで攻撃、1つの段を全部正解するとすみかを取り戻す（9つでたおす）。ハート3つ・3問連続正解でかいふく・けがの式は5〜8問後にリベンジ出題。合体攻撃・最後の総攻撃・81ぴきのパレード。中断して「つづきから」再開。図鑑のボス枠10番めにワスレドンのシール
- 決めた仕様（理由も一言）：
  - ひらく条件＝81ぴき全部こども以上（なかま全員が攻撃に出られるように）
  - 勝ち負けは81問やりきったかだけ。段階で変わるのは技の派手さだけ（育成が遅い子も勝てる。育てる理由は技がかっこよくなること）
  - 図鑑：正解はランダム10問と同じに進む。まちがえてもにげない（長い戦いで次々にげるのはつらい）。時間切れもまちがいと同じ
  - 演出はタッチでとばせる。まちがいの正しい答えだけは1秒とばせない（覚えなおすため）
  - localStorage `kuku_lastboss_v1`（open・best・save）
- 未解決・次にやること：実機（学校のタブレット）で5秒の長さと演出の待ち時間を確かめる／main への反映
