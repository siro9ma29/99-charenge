## 0. 決定事項（2026-10-27）
- 4択・1問ミスで終了の形は**そのまま残し**、答えるたびに図鑑の記録が進む仕組みを上に重ねる
- 図鑑は**1の段も含めた81**。段えらびに1の段を追加した（ランダム10問は従来どおり1の段と「N×1」を出さない）
- **1人1台**の前提なので、名前（出席番号）えらびは付けない
- v3.0：**性別に関係なく好まれるよう、「生き物を集めて育てる」型に変更**。特定の作品（ポケモン・ビックリマン等）のキャラクター・名前・見た目は使わず、すべてオリジナル
  - 絵柄：丸くて目の大きいこども → まゆ・大きなパーツでかっこよくなるしんか。ピンク＝女の子／青＝男の子のような色分けはしない
  - 名前：性別を感じさせない音（例：ポチャ → ポチャリオン、サンゴロ → サンゴレム）。プリンセス・キング等は使わない
- v3.2：**上り・下り・ランダムの3パターンはすべて残す**（上り＝唱えて覚える導入、下り＝唱える順番に頼らない、ランダム＝1つ1つの式を単独で思い出す＝筆算やわり算で必要な力）。**段ごとに 上り → 下り → ランダム の順に解放**
- v3.3：**学び方の段階 ＝ モンスターの育ち方**
  - 上り＝たまご、下り＝うまれる、段のランダム＝しんか、**ランダム10問＝かがやき**（しんかの さらに上。ランダム10問の意味づけ）
  - **「次の日以降に正解」の条件は残す**（日をあけても言えるかを確かめる）
  - 上りでは まちがえても にげない（覚えはじめの段階のため）

- v3.5（2026-11-07）：**ランダム10問の10問目は「ぬし」との勝負**
  - 出てくるのは、10問目の式の段のぬし（7×8 なら「よぞらの ぬし」）。まだ出現していない段は、かげ（シルエット）で「7の段の ぬし」と出す（集める目標になる）
  - **出題・判定はそのまま**（演出だけ重ねる）。ぬしが出てくる約1.3秒はタイマーを止め、タイム・ベスト・ゴーストにふくめない（これまでの記録と比べられるように）
  - 正解：ぬしがゆれて小さくなり「👑 ぬしに かった!」。結果画面に「○○に かった!」（かげのときは「9ひきを そろえると すがたが 見えるよ」）
  - まちがい：ぬしがはねて、結果画面に「○○は つよかった… つぎは かてるよ!」（責めない）
  - 新しい記録（localStorage）は ふやさない
- v3.6（2026-11-07）：**「⚡ 3びょう チャレンジ」**（ランダム10問の発展モード）
  - **ひらく条件**：ランダム10問をクリア ＋ 81ぴき ぜんぶ かがやき（にげている なかまは数えない）。九九が身についた子だけの発展にし、ふつうのランダム10問はそのまま残す（覚えている途中の子に時間の負担をかけない）
  - 一度ひらいたら閉じない（あとで にげても あそべる）。ロック中はランダム10問のパネルに、2つの条件と「いま ○/81」を表示
  - 出題はランダム10問と同じ（10問目は ぬし）。**1問ごとに3秒**。時間は答えが出た瞬間〜タップまで（正解の演出・ぬしの登場は ふくめない）。のこり1秒でバーが赤く点滅
  - 時間切れ：⏰ を出し、正しい答えを光らせて終了。**図鑑には記録しない**（まちがいに数えない・にげない。タップの遅れで にがさないため）
  - まちがい：ふつうのランダム10問と同じ（にげる）
  - ベスト3・スタンプ・ゴーストは別に記録

## 1. 目的とコンセプト
- **「九九モンスターを集めて育てよう」**（コレクション＋育成）＋**「ベストのじぶんに勝とう」**（ゴースト対戦）
- 図鑑の段階＝その式の到達度：たまご＝順番に唱えて言える／こども＝逆からでも言える／しんか＝段の中でばらばらでも言える／**かがやき＝ほかの段とまざっても、日をあけても言える**
- 毎日少しずつ取り組む習慣につなげる
- 競う相手は過去の自分だけにする

## 2. 九九モンスター
- 段ごとのすみか：1もり／2くさはら／3うみ／4そら／5かざん／6ゆきやま／7よぞら／8さばく／9たからの どうくつ
- 81ひき × 段階（たまご・こども・しんか・かがやき）＋ボス9ひき（「○○の ぬし」）
- かがやきは、しんかの姿に金の光（オーラと ✦）をつけて描く
- 絵はすべてSVGで描く。オフラインで表示でき、ファイル1つにおさまる

## 3. ルール
| 段階 | どこで | 条件 |
|---|---|---|
| 🥚 たまご | 上り | 同じ式に**3回つづけて正解**（プレイをまたいで数える） |
| 🐣 こども（うまれる） | 下り | たまごになった**次の日以降**に正解 |
| ✨ しんか | 段のランダム・ランダム10問 | うまれた**次の日以降**に正解 |
| 🌟 かがやき | ランダム10問 | しんかした**次の日以降**に正解。※1の段と「○×1」はランダム10問に出ないので、段のランダムで かがやく |

| できごと | 条件 |
|---|---|
| にげる | なかまにした式を、下り・ランダム・ランダム10問でまちがえる（👣。段階は消えない）。**上りでは にげない** |
| とりもどす | にげた式に**2回つづけて正解** |
| ボス | 1つの段の9ひきがそろうと出現（一度出たら消えない） |

- 同じ日に何回正解しても、すすむのは1日1段階まで
- 図鑑の詳しい表示で「あした いこうに 下りで 7×8 に正解すると うまれるよ」のように、次に使う といかたと目標を出す

### といかたの解放（段ごと）
| といかた | ひらく条件 | 育つ段階 |
|---|---|---|
| ⬆️ 上り | はじめから | たまご |
| ⬇️ 下り | その段の上りをクリア（全問正解） | うまれる |
| 🔀 ランダム | その段の下りをクリア | しんか（1の段・○×1 は かがやきも） |
| 🎲 ランダム10問 | はじめから | しんか・かがやき |

- まだ ひらいていないボタンは🔒と点線。タッチすると「4の段の 上りを クリアすると ひらくよ」と表示
- 段えらびのボタンの下に、選んだ といかたで何が起きるかを表示（例「🐣 下りで 正解すると、たまごが うまれるよ(つぎの日 いこう)」）
- ランダム10問のパネルに「🌟 しんかした モンスターの 式に、つぎの日 いこうに ここで 正解すると かがやくよ!」
- クリアで次がひらいたときは、結果画面に「🔓 4の段の 下りが ひらいた!」と「下りに すすむ」ボタン

## 4. 画面
| 画面 | 内容 |
|---|---|
| メニュー（モンスターの せかい） | 9つのすみかの景色を3×3のマップに並べる。各すみかに、集めたモンスター（育っているものを優先、3びきまで）が立ち、「○/9」とボス（出ていれば）を表示。9ひきそろうと金のわく、0ぴきは景色が暗く「？」。すみかをタッチすると図鑑タブが開き、その段の列が光る |
| 九九図鑑タブ | なかま(○/81)・ボス・にげた なかま、段階ごとの数（たまご／こども／しんか／かがやき／ボス）、9×9のマス、ボス9枠。タッチすると大きなシールと次の目標 |
| 出題中 | ランダム10問の10問目は ぬしが登場（上の v3.5）。「🥚 たまごGET!」「🐣 うまれた!」「✨ しんか!」「🌟 かがやいた!」「👑 ボスあらわる!」を小さなお知らせで表示 |
| 結果画面 | 新しいたまご・ボスは裏向きのパックでめくる。育った なかまは「まえのすがた」が裏にあり、タッチで新しいすがたに変わる |

- シールのわく：たまご＝ノーマル（★）、こども＝キラ（★★・銀）、しんか＝ホロ（★★★・にじ色）、**かがやき＝金（★★★★・光が回る）**、ボス＝レジェンド（★★★★★）
- キラ以上のシールは、さわると傾いて光が動く
